Super short description:
Scrivi is an original upright monoline handwriting typeface by Alessandro
Resch, with separated letters, compact spacing and restrained flourishes.
It offers one Regular style, 392 encoded characters and GF Latin Core coverage,
editable UFO sources, original drawing data and a reproducible fontmake build.

Disclosure of AI assistance:
The project was developed with ChatGPT/Codex assistance in drawing construction,
font engineering, build scripts, testing, documentation and release preparation.
Alessandro Resch directed the design decisions and reviewed visual specimens.

Naming review requested:
The intended family name is Scrivi. AR refers to the author's initials.
The published onboarding guide excludes copyright-holder initials/acronyms;
FontBakery's generic naming exception is not project approval. Please advise
whether an exception is possible or a different catalog name is required.
No name-policy compliance declaration is made in this draft.
